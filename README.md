# VEDAME SPACE — Telegram-бот (@VedaMe_Space_bot)

Бот для вебинаров/практик/расстановок и закрытого клуба VEDA SANCTUM
(Alena Veda). Полностью самостоятельный проект — весь контент, тексты,
цены и правила меняются из встроенной админ-панели внутри самого
Telegram, без правки кода.

## На чём написан

| Что | Версия / инструмент |
|---|---|
| Язык | Python 3.14 (нужен минимум 3.10) |
| Библиотека для Telegram | [aiogram](https://docs.aiogram.dev/) 3.28.2 — асинхронный фреймворк для ботов |
| База данных | SQLite (один файл `webinars.db`, без отдельного сервера БД) |
| Планировщик задач | APScheduler 3.11.2 — рассылки и напоминания по расписанию |
| Переменные окружения | python-dotenv 1.0.1 — токен бота хранится в `.env`, не в коде |

Никаких внешних сервисов, очередей или облачных баз — один процесс
Python, один файл SQLite рядом с ним. Это специально: минимум движущихся
частей, легко переносить и восстанавливать из простой резервной копии.

## Структура проекта

```
main.py            — вся логика бота: обработчики кнопок и сообщений,
                      админ-панель, автоматические рассылки (~7500 строк)
database.py         — все функции чтения/записи в SQLite, создание таблиц
                      и миграций при первом запуске (~2700 строк)
rituals.py          — отдельный модуль: календарь ритуалов VEDA SANCTUM
                      (даты, тексты, напоминания) (~530 строк)
config.py           — загрузка токена бота и базовых констант из .env
requirements.txt     — список библиотек для `pip install`
start_bot.bat        — Windows-скрипт запуска с автоперезапуском при сбое
                      (для сервера на Linux вместо него — systemd, см. ниже)
deploy/
  DEPLOY_GUIDE.md     — пошаговая инструкция переноса на сервер
  webinars-bot.service — шаблон systemd-службы для автозапуска на Linux
.env                — токен бота (BOT_TOKEN=...) — НЕ в git, передаётся отдельно
webinars.db          — сама база данных с реальными подписчиками — НЕ в git,
                      переносится отдельно (см. DEPLOY_GUIDE.md)
backups/             — ежедневные резервные копии базы (создаются ботом сам,
                      не в git)
```

## Как устроены данные

Одна база SQLite, ключевые таблицы:

- **users** — все, кто хоть раз нажал /start в боте
- **sanctum_membership** — кто состоит в VEDA SANCTUM, до какой даты, по какой цене
- **webinars** / **webinar_reviews** — вебинары/практики/расстановки и отзывы к ним
- **registrations** — заявки на оплату (вебинар или Sanctum) и их статус
- **feed_posts** — архив публикаций
- **questions** — вопросы от людей и ответы на них
- **ritual_events** — даты календаря ритуалов
- **admins** / **admin_permissions** — кто администратор и что ему разрешено
- **settings** — САМАЯ важная таблица: буквально весь текст, который бот
  показывает людям (приветствия, поздравления, кнопки, цены, сроки),
  хранится здесь как пары ключ-значение. Админ-панель — это просто
  удобный интерфейс для правки этой таблицы; в коде почти нигде нет
  "зашитого" текста

Именно из-за таблицы `settings` бот не требует правок кода для обычной
работы — Alena управляет всем сама из Telegram (см. вопрос ниже).

## Как перенести на сервер

Полная пошаговая инструкция — в [`deploy/DEPLOY_GUIDE.md`](deploy/DEPLOY_GUIDE.md).
Коротко: клонировать этот репозиторий по deploy-ключу (доступ только на
чтение), поставить Python-зависимости, перенести `.env` и `webinars.db`
отдельно (не через git), настроить автозапуск через systemd — шаблон
уже готов в `deploy/webinars-bot.service`.
